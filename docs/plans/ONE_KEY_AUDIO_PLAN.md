# One key plays with sound — audio without ElevenLabs

> **Status: proposed 2026-09-25, not started.** Nothing below is built. The
> screens it touches (the narrator's subtitle, TALK's push-to-talk, the voice
> line on a companion) go through a design pass before any code. Facts about
> Google and OpenAI were checked against their docs on 2026-09-25; the ones
> marked **unverified** are the first spike (§6).

## Why

A player brings one key — Gemini or OpenAI, picked in ACCOUNT — and the game
plays. Except the sound: six lanes of it run on ElevenLabs, which is a second
account, a second bill and, for a stranger, a second thing to understand
before they hear anything. Without that key today:

- **Music, ambience, foley and the consequence bed are silent.** `scene_audio.is_available()`
  is false, the endpoints return null URLs, and the stock stingers are not
  shipped (`assets/music/*` is gitignored) — they are generated by ElevenLabs
  on first use, so a fresh install has none.
- **TALK and the narrator still speak — on our account.** With no key they fall
  back to a public Convai agent id baked into `engine.py:269`
  (`agent_1601kxh3rz2hej9swfs75dv33q78`). Every player without a key is
  talking to that agent, billed to whoever owns it. The narrator is voiced the
  same way: one agent session per line, `firstMessage` = the line, a fake
  silent mic (`standalone.js:27496-27727`). This must not reach strangers.
- Voice design is off (`voice_design.is_available` needs the key); NPCs get a
  hashed stock ElevenLabs id from `voices.json`.

It is also the expensive part. The distribution plan's measured 15-minute run
cost $4.63, of which ElevenLabs music (19 tracks) and sound effects (30 clips)
were **$1.74, 38%**. `BILLING_LIVE_PLAN.md`'s 30 days: sound $33.04, music
$25.70, voice design $16.95.

## What Google and OpenAI can do now

| Design a voice from words | **Yes.** `POST /v1beta/voices` `type:"prompted"` + a description → a persistent `voice_…` id + a sample. 3.8 TTS models only. 200 stored voices per project, each lives 1 year; stateless `voicekey_…` for 7 days. Creation price **unverified** | **No.** Custom voices are audio cloning, sales-gated | **Google only.** OpenAI gets a prebuilt voice + a stored instruction |
| Live conversation | `gemini-3.8-live` GA, WebSocket, same voices as TTS, ~$0.005/min in + ~$0.018/min out. Whether a *designed* voice works in Live is **unverified** | `gpt-realtime-2.1` $32/$64 per 1M audio tokens; mini $10/$20 | Gemini Live is the duplex upgrade; OpenAI Realtime is too dear to default to |
| Music | Lyria: `lyria-3-clip-preview` 30 s $0.04, `lyria-3.5` ~2 min songs $0.08, instrumental on request, 44.1 kHz stereo. **Paid tier only**, Interactions API (not `generateContent`) | None | **Google only, and not on a free key** |
| Sound effects / foley / ambience | None (TTS docs say not to ask for thuds). Veo/Omni make audio with video at $0.05–0.40 per *second* — not a foley source | None (Sora's API shut down 2026-09-24) | **Nobody.** This lane becomes a library |
| Dictation | `gemini-3.5-transcribe` ~$0.003/min | `gpt-transcribe` $0.0045/min | Both; already wired (`engine._transcribe_audio` + the bridge) |

So the answer is not "one replacement" but **a different tool per lane**,
chosen so that a Gemini key alone gives everything and an OpenAI key alone
gives everything but designed voices and generated music.

## The plan, lane by lane

### 1. Narrator → text-to-speech (both providers)

The narrator speaks text we already have, so it should never have been an agent
session. A new `speech.py` owns one call, `say(text, voice) -> audio path`:

- **Gemini:** 3.8 Flash TTS, the narrator's designed voice (below), the
  moment's feeling in `style` ("low, close to the mic, as if the room might
  hear").
- **OpenAI:** `gpt-4o-mini-tts`, `onyx` or `cedar`, the same sentence in
  `instructions`.
- Through the bridge like everything else: `speech.py` speaks Gemini;
  `provider_bridge` learns one more translation (TTS `generateContent` →
  `/v1/audio/speech`). So nothing has to ask which provider is playing.

Server-side `_tts_synthesize` and the `speak:true` path already exist
(`engine.py:17441`, `/api/narrator/narrate`); the client stops opening Convai
sessions and plays the returned file. Cache by `sha1(text, voice, style)` in
the session's `audio/` so a replayed tape costs nothing. Narrator lines start
being metered — they are not today (only TALK reports seconds).

### 2. A voice per character → Gemini Voice Design, or a steered stock voice

The voice record on a companion becomes provider-neutral. It already carries
the thing that matters — the description, "the regeneration seed"
(`docs/MOMENTS.md:253`):

```json
"voice": {
  "description": "A hoarse man in his sixties, slow, dry, desert-flat vowels.",
  "engine": "gemini-designed" | "openai-steered" | "elevenlabs",
  "id": "voice_…" | "cedar",
  "style": "…",          // OpenAI: the whole instruction; Gemini: situational only
  "project": "<hash of the key's project>",
  "updated_at": "…"
}
```

- **Gemini:** design from `brief_for_subject`'s description (already built for
  ElevenLabs' Voice Design — gender, age, timbre, emotion rules). Google's own
  advice matches the brief's shape: permanent traits in the designed voice, only
  the moment's emotion in `style`.
- **OpenAI:** the same brief picks one of the 13 voices deterministically
  (gender × age × timbre → voice, a table in `voices.json`) and the description
  becomes the `instructions`. Thirteen timbres, delivery steered — honest about
  being the lesser path.
- **A voice id belongs to the player's Google project.** Ids do not travel: a
  new key, a shared character (see `TRADING_PLAN.md`), or a year's expiry means
  the voice is redesigned from `description`. The `project` field says when.
  `voice_design.py`'s machinery already does this for stale ElevenLabs ids
  (`_companion_voice_for_subject`, the regen watcher) and already manages a
  slot cap with LRU eviction and a sweep — 200 per project replaces
  ElevenLabs' workspace slots.
- **Session NPCs use stateless `voicekey_…` (7 days) if the spike shows they
  don't count against the 200;** only companions get stored voices.
- **The gateway (distribution plan, G) changes this.** Keyless players would
  design into *our* project — 200 voices shared by everyone. Until that is
  solved, gateway players get the steered-stock path, even on Gemini.

### 3. TALK → push-to-talk first, Gemini Live second

TALK today is a full-duplex ElevenLabs agent opened from the browser. Replace
it in two steps, so the first works on both providers:

1. **Push-to-talk turns.** Hold to speak → `/api/transcribe` (exists, both
   providers) → `/api/talk/message` (exists — the text-mode reply, already
   vision-grounded) → `speech.say` in the character's voice. ~2–4 s a turn.
   The character's line can be shown as it is spoken. Metered per call, not
   per minute, and it never runs up a bill by leaving a mic open.
2. **Gemini Live duplex** where the key is Gemini and the spike shows designed
   voices work in Live: `gemini_live_talk.py` exists behind `TALK_LIVE_API=1`
   with no client and no voice config; it gains both. OpenAI players stay on
   push-to-talk (Realtime is 5–10× Gemini Live's price).

### 4. Sound effects → a shipped library the turn chooses from

No provider generates foley on one key, and generated foley was a third of a
run's cost. So stop generating it:

- **A catalog of ~300 sounds in a fixed vocabulary:** ambience beds (desert
  wind, fluorescent hum, rain on sheet metal, distant highway…), foley verbs
  (gravel steps, chain-link climb, door kicked, shutter click, radio static…),
  encounter stingers (the 12 `STOCK_STINGERS`) and consequence beds. OGG/Opus,
  ~40–60 MB, shipped in the installer (`tools/ship_layout.py`) and in the
  gateway's shared cache.
- **Where it comes from:** either a licensed royalty-free library (Sonniss'
  GDC bundles are free for commercial use, real recordings), or generated once
  on our ElevenLabs account under a plan whose terms allow redistribution.
  **Check the licence before either.**
- **The turn names what it hears.** The consequence JSON gains
  `sound: {ambience, foley[]}` chosen from the vocabulary (the list goes in the
  prompt, ~1 KB). No extra call. The client varies each play (pitch ±3%, filter,
  gain, start offset) so a repeated door doesn't sound pasted.
- ElevenLabs stays an optional "More keys" upgrade that generates bespoke clips
  over the library, as now. It stops being required for any sound at all.

### 5. Music → Lyria on Gemini, a score library everywhere

- **Gemini on a paid key:** `lyria-3-clip-preview` for the scene/conversation/
  encounter beds (30 s, $0.04 — cheaper than Eleven Music's $0.075 per 30 s),
  instrumental. The prompts in `scene_audio` carry over. Lyria was this game's
  first music engine (commit `1f31602`) before Eleven Music replaced it.
- **Everyone else (free Gemini tier, OpenAI, keyless):** a shipped score of
  ~20 loops tagged by phase and mood (calm / escalating / critical / encounter
  / camp / menu). The menu loop already works this way.
- `lyria-realtime-exp` (live-steered music) is experimental and unpriced.
  Not now.

### 6. Before any of it — the spike (1 day, real keys)

Answer these by calling the APIs, not from docs:

1. Does creating a designed voice cost anything, and does it work on a free
   AI Studio key?
2. Do `voicekey_…` stateless keys count against the 200?
3. Does a designed `voice_…` id work in `gemini-3.8-live`?
4. Latency: first audio byte for a 25-word narrator line, Gemini Flash TTS vs
   Flash-Lite vs `gpt-4o-mini-tts`. The narrator has to land under a turn's
   picture.
5. Consistency: the same OpenAI voice + instruction, ten lines — does it stay
   one person? Record them; play them to Matt.
6. Lyria clip: does "instrumental, dread, low drones, 1993 desert" come back
   usable, and how long does it take?

`tools/audio_probe.py` in the probe pattern; the recordings go to
`_claude_pull/audio_spike/`.

A0 is a release blocker. A2 and A3 are what a stranger notices. Everything is
wired into both editors where it has a control (the editor's voice pickers
become a provider-aware list; the music panel keeps Lyria and loops).

## Tests that encode the invariants

- A keyless session makes no request to `api.elevenlabs.io` (mock the session,
  assert).
- A voice record is never missing `description` — the one field that survives
  every provider change.
- Every sound the consequence prompt may name exists in the catalog, and every
  catalog file is referenced by the vocabulary (the `unwired_keys` pattern).
- `provider_bridge` answers a TTS call on OpenAI with audio (in
  `test_provider_bridge`).
- Existing suites to move: `test_scene_audio`, `test_voice_design`,
  `test_talk_voice`, `test_conversation_moments`, `test_keys_store`,
  `test_cost_tracker`, `test_pricing`, `test_billing` + the e2e suites that
  assert TALK/narrator behaviour.

## Decisions for Matt

- **ElevenLabs stays as an optional upgrade key, or goes entirely?** Default
  here: stays optional, off the default path, removed from the gateway's needs
  (no commercial/OEM plan to negotiate).
- **Sound library source:** licensed library vs generated once on ElevenLabs.
- **OpenAI players' voices** are thirteen steered timbres. Acceptable, or
  should ACCOUNT say "voices are best on Gemini"?
